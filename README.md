# Анализ населения и инфляции России

## Выполнили
- Лена (14 вариант) - анализ численности населения по субъектам РФ
- Олеся (10 вариант) - анализ инфляции

## Функционал
- Загрузка данных из JSON-файлов
- Отображение в таблице
- Построение графиков
- Прогнозирование методом скользящей средней
- Экспорт графиков в PNG

## Ветки
- main - финальная версия
- dev - разработка
- feature/population-analysis - 14 вариант
- feature/inflation-analysis - 10 вариант

## Как запустить
Открыть PopulationAndInflationAnalysis.sln в Visual Studio → F5
